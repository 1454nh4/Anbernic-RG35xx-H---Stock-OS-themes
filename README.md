# Anbernic RG35xx-H Stock-OS mod themes

[PT]
Descrição: Repositório de temas para o Stock OS mod do Anbernic RG35xx-H.

  OBS: "Stock_theme_bak.zip" são arquivos para a instalação através da função "restaurar tema official" 
  do aplicativo Theme Manager do Stock OS mod [(cbepx)](https://github.com/cbepx-me/Anbernic-H700-RG-xx-StockOS-Modification). Pastas que seguem a estrutura de nome "NomeDoTema/APPS/..." servem para a instalação através da função "instalar tema" do Theme Manager.
  
  Não consegui fazer os temas aparecerem movendo os arquivos manualmente (sem o Theme Manager), mas caso saibam como, devem saber que é só extrair o .ZIP para ter acesso aos arquivos e tentarem vocês mesmos. Caso não queira o Stock OS mod, instalar o Theme Manager separadamente também funciona, basta baixar o ficheiro "Theme_Manager" e movê-lo para o diretório "APPS" do cartão SD e executá-lo normalmente. 
  
  VERSÃO UTILIZADA (ver seção "releases" da pagina GitHub do Stock OS mod do cbepx): "RG35XXH-V1.2.4-BASE-20260522-mod-v3.9.9.img"
  
Instalação: 

- Método 1 (função "restaurar tema oficial"):
  . substituir o "Stock_theme_bak.zip" padrão do diretório ".../Anbernic/backup" pelo arquivo .zip que contém os visuais desejados e renomea-lo de acordo.
  . executar a função "restaurar tema oficial" no dispositivo.
  (SEMPRE GUARDAR BACKUP DO .ZIP PADRÃO)
  
- Método 2 (função "instalar tema"):
  . basta adicionar a pasta .zip ao diretório ".../Anbernic/themes" (criar um caso não exista).
  . executar função "instalar tema" no dispositivo e selecionar o .zip adicionado


  
[ENG]
Description: Theme repository for the Stock OS the Anbernic RG35xx-H.

  OBS: "Stock_theme_bak.zip" are files meant for installation via the "restore official theme" function in the Theme Manager app from the Stock OS mod [(cbepx)](https://github.com/cbepx-me/Anbernic-H700-RG-xx-StockOS-Modification). Folders that follow the name structure "ThemeName/APPS/..." are meant for installations via "install theme" function on Theme Manager. 
  
  I couldn't get the themes to appear by moving the files manually (without the Theme Manager), but if you happen to know how, you can simply extract the .ZIP file to access the contents and try it yourself. In case you don't want the Stock OS mod, installing the Theme Manager separately works fine, just download the "Theme_Manager" folder and move to SD card "APPS" directory. 
  
  VERSION USED (see "releases" section on cbepx Stock OS mod GitHub wepage): "RG35XXH-V1.2.4-BASE-20260522-mod-v3.9.9.img"
  
Installation:

- Method 1 ("restore official theme" function):
  . Replace the default "Stock_theme_bak.zip" file located in the ".../Anbernic/backup" directory with the .zip file containing your desired themes, and rename it accordingly.
  . Run the "restore official theme" function on the device.
  (ALWAYS KEEP A BACKUP OF THE DEFAULT .ZIP FILE)
  
- Method 2 ("install theme" function):
  . Simply add the .zip file to the ".../Anbernic/themes" directory (create the folder if it does not exist).
  . Run the "install theme" function on the device and select the .zip file you added.
