# Anbernic-RG35xx-H---Stock-OS-mod-themes
Descrição: Repositório de temas para o Stock OS mod do Anbernic RG35xx H
  OBS: Estrutura dos diretórios do arquivo .ZIP organizada para a instalação através da função "restaurar tema official" 
  do aplicativo Theme Manager do Stock OS mod (cbepx). Não consegui fazer os temas aparecerem movendo os arquivos 
  manualmente (sem o Stock OS mod), mas caso saibam como, devem saber que é só extrair o .ZIP para ter acesso aos arquivos 
  e tentarem vocês mesmos.
